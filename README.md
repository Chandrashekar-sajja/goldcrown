# GoldCrown Website UI

This project is a static frontend website built using HTML and CSS.  
It simulates a financial dashboard platform with pages for login, registration, dashboard statistics, account activation, and fund deposit.

The project focuses on user interface design and page layout.

## Features

- Landing page
- User login page
- User registration page
- Dashboard with earning statistics
- Account activation form
- Deposit fund page
- Sidebar navigation menu

## Technologies Used

- HTML5
- CSS3
- Font Awesome icons

## Project Structure

index.html – Home page  
login.html – User login page  
register.html – User registration page  
dashboard.html – Dashboard interface  
activation.html – Account activation page  
depositfund.html – Deposit funds page  

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser
